Antes de empezar

Recomendamos usar GRID GENERATOR desde un ordenador

GRID GENERATOR está optimizado para pantallas de ordenador, donde resulta más cómodo configurar los módulos, ajustar los elementos y trabajar con la vista previa.

Puedes utilizarlo desde un móvil o una tablet, pero algunos controles pueden resultar menos cómodos.

¡Gracias por usar GRID GENERATOR!

Cableado LED
1. Activa Editar cableado.
2. Haz clic en el primer módulo y sigue el orden de conexión.
3. Para otra salida/puerto, pulsa Nueva cadena.
Las flechas indican el recorrido y los números el orden de conexión. Haz clic en el último módulo para deshacer ese paso.
Asignados automáticamente a cada cadena.
